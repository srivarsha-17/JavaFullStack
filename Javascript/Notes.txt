Non Primitive DataTypes:
  1. Arrays
    -> contiguous allocation of memory where data is stored in the sequence
    -> linear data structures used to store collection of homogeneous data or
    heterogeeous data

    In JS Array Declaration : 
    1. literal way : 
    Eg ; let arr = [1,2,3,4,5]


    2. using new keyword / object:
    Eg : let arr = new Array(10,20,30,40)


    Array inbuilt functions : 
    let arr1 = [null,true,500,'javascript']

    1.push():
      used to push element at the end of the array 

      Eg: arr1.push(50) => [null,true,500,'js',50] => added at the end


    2.spread operator (...):
    Eg : arr1 = [10,20,30,40]
        arr2 = [1,2,3,4,5]
        arr2.push(...arr1)
        now arr2 = [1,2,3,4,5,10,20,30,40,50] // arr2 is added to arr1

        arr2.push(arr1) // the entire array is added as a new element

        now arr2 = [1,2,3,4,5,[10,20,30,40,50]]

    
    3. shift()

    shift opertor is used to remove element at the 0th position

    4. unshift()

    unshift operator is used to add element at the 0th position



    push => add at the end
    pop => remvoe at the end
    shift => add at the start
    unshift => remvoe at the start
